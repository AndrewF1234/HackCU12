# The Issue
<p>Signing up for classes for the next semester is always a handful. Each major has its own major-specific requirements in addition to general education courses within the college. Keeping track of prerequisites for each class makes planning for the next few semesters difficult. If you add a minor or another major, it becomes even more complicated to keep track of overlapping classes and classes that you need to do for each specific major.</p>
<p>While the current degree audit is a very good tool to keep track of requirements for each major, it does not provide a holistic perspective on all the classes you need to take. The degree audit provides information for each major separately, not taking into account classes from other majors or minors that a student is taking. This makes the degree audit inconvenient.</p>

# The Solution
<p>This new website will allow a student to easily compare major-specific classes and identify overlapping classes. Rather than just showing future requirements, this website shows a sample plan for the student for the next several years, allowing the student to make informed decisions about their education and future.</p>
